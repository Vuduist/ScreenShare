# ScreenShare

Показ экрана коллеге по локальной сети в один клик. Только картинка: никакого удалённого управления, никаких серверов, никакого интернета.

Сценарий: «О, смотри, что нашёл!» → **Start** → у коллеги тут же появляется окно с вашим экраном → посмотрели → **Stop** → окно пропало.

## Как пользоваться

1. Скачайте `screenshare.exe` из [последнего релиза](../../releases/latest) и запустите на обоих компьютерах. Установка не нужна.
2. При первом запуске Windows спросит, разрешить ли программе доступ к сети, — нажмите «Разрешить» (нужно для приёма входящих показов, порт `7878`).
3. В главном окне:
   * **IP-адрес коллеги** — свой адрес каждый видит в правом верхнем углу окна («Мой IP»).
   * **Экран** — какой монитор показывать.
   * **Start** — начать показ. **Stop** — закончить.
4. У коллеги автоматически откроется окно «Экран: ИМЯ-ПК (IP)». Его можно двигать, менять размер, сворачивать. Закрытие окна лишь прячет его (вернуть можно кнопкой «Показать окно» в главном окне), а при нажатии **Stop** на стороне отправителя окно исчезает само.

Оба компьютера равноправны: каждый может и показывать, и смотреть, в том числе одновременно.

Закрытие главного окна сворачивает программу в трей; выход — через меню иконки в трее.

В разделе «Настройки» можно поменять частоту кадров (по умолчанию 15) и качество JPEG (по умолчанию 70). Последние введённый IP и выбранный экран запоминаются.

## Если не подключается

* На принимающем компьютере должен быть запущен ScreenShare.
* Порт `7878/tcp` должен быть открыт во входящих правилах брандмауэра принимающего компьютера. Если при первом запуске вы нажали «Отмена», добавьте правило вручную (от администратора):

  ```powershell
  netsh advfirewall firewall add rule name="ScreenShare" dir=in action=allow protocol=TCP localport=7878
  ```

* Компьютеры должны быть в одной сети (или сети должны маршрутизироваться между собой). Если нужен другой порт, укажите адрес в виде `192.168.1.42:7878`, но порт приёма пока фиксированный.

## Безопасность

Программа рассчитана на доверенную локальную сеть: авторизации нет, любой, кто может подключиться к порту `7878`, может показать вам свой экран (но не увидеть ваш — экран уходит только туда, куда вы сами нажали Start). Трафик не шифруется. Не пробрасывайте порт в интернет.

## Как это работает

* Захват экрана — [xcap](https://crates.io/crates/xcap), кадры кодируются в JPEG ([jpeg-encoder](https://crates.io/crates/jpeg-encoder)) и отправляются по TCP. Неизменившиеся кадры не отправляются, поэтому статичный экран почти не грузит сеть.
* Приём — [zune-jpeg](https://crates.io/crates/zune-jpeg), отрисовка — [egui/eframe](https://github.com/emilk/egui), окна показа — отдельные viewport'ы egui, иконка в трее — [tray-icon](https://crates.io/crates/tray-icon).
* Протокол описан в начале [`src/net.rs`](src/net.rs).

## Сборка из исходников

Нужен [Rust](https://rustup.rs) (stable).

```bash
cargo build --release
```

Готовый файл: `target/release/screenshare.exe`.

Код кроссплатформенный (Windows / Linux / macOS), но проверялся только на Windows.
